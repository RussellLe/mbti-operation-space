# 步骤 4：引号修正

## 禁用规则

禁用把引号当强调符号。引号只用于两种情况：

1. **角色实际说出口的台词**（能在剧情素材中找到出处）
2. **确有必要标示的术语**

### 以下用法一律禁止

- 用引号包裹自己编写的短语来制造重点
  - 例：`释放"差一步就失去她"的后怕`
- 用引号包裹心理活动或情绪概括，伪装成"引用"来绕过其他禁令
- 用引号给一个普通词语加上"特殊含义"的暗示

## 判断标准

如果引号里的内容不是角色原话（能在剧情素材中找到出处），就不该加引号。

## 执行动作

1. 找出目标文档中所有使用引号的位置
2. 逐个检查：引号内的内容是否为角色原话？
   - **是** → 保留
   - **不是** → 删掉引号，把意思直接写进句子里。想强调就用准确的措辞本身来强调，不要靠标点符号
