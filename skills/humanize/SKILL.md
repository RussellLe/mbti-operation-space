# 文风人性化（写作 & 重写）

只要输出语言是中文，就把这份文件视为强约束。若它与其他通用写作说明冲突，以这份文件为准。

## 根规则（贯穿全程）

写人的时候，站在房间里面写，不要站在房间外面写。句子的主语应该是人或人的身体，动词是人做的动作，判断贴着具体场景给出。如果你遇到一个句子读起来像是站在房间外面写的，就应当重写。

行文语气的详细要求见 `./tone.md`，贯穿全部流程。

## 约束清单

以下每份文件定义一条具体约束，两种模式共用：

| 文件 | 关注点 |
|------|--------|
| `./tone.md` | 行文语气：在场的闲聊者 |
| `./subject_test.md` | 主语必须是人，不是抽象名词 |
| `./transition_fix.md` | 消灭"先否定 A，再肯定 B"的转折句 |
| `./symmetry_fix.md` | 消灭对称句、三项并列、同形堆叠 |
| `./quote_fix.md` | 引号只用于原话和必要术语 |
| `./ai_tone_fix.md` | 清除 AI 腔、段尾拔高、社媒金句 |
| `./sentence_polish.md` | 一句一判断，删桥句，去漂亮废话 |
| `./final_check.md` | 终检通读 |

## 模式 A：重写已有文档

用户指定一份已有文档，逐轮修正直到达标。

调用示例：`/humanize rewrite <目标文档路径>`
若用户只写了 `/humanize <路径>` 且该路径指向已有文件，默认进入此模式。

### 执行流程

**每完成一个步骤，立即输出修改后的完整文档，然后再进入下一步。不要跳步，不要合并步骤，不要等全部读完再动手。**

1. **语气重写** — 读取 `./tone.md`，按行文语气要求对整份文档重写。
2. **主语测试** — 读取 `./subject_test.md`，逐句检查并修正。
3. **转折句修正** — 读取 `./transition_fix.md`，逐句检查并修正。
4. **对称句与排比修正** — 读取 `./symmetry_fix.md`，逐句检查并修正。
5. **引号修正** — 读取 `./quote_fix.md`，逐句检查并修正。
6. **AI 腔清理** — 读取 `./ai_tone_fix.md`，逐句检查并修正。
7. **句子打磨** — 读取 `./sentence_polish.md`，逐句检查并修正。
8. **终检通读** — 读取 `./final_check.md`，整体通读，捕捉遗漏或新引入的问题，输出最终版本。

## 模式 B：指导写作新文档

用户提供写作素材（大纲、剧情梗概、角色信息等），按本文件的全部约束从头生成文档。

调用示例：`/humanize write <素材路径或直接描述>`

### 执行流程

1. **加载约束** — 一次性读取上方约束清单中的所有 `.md` 文件，作为写作时的并行约束。
2. **生成初稿** — 根据用户提供的素材，在全部约束的同时约束下写出完整文档。写作过程中，根规则和行文语气是第一优先级，其余约束同步遵守。输出完整初稿。
3. **自检修正** — 拿初稿按模式 A 的步骤 2–7 逐轮过一遍，每轮只关注对应约束，发现问题立即修正并输出。
4. **终检通读** — 读取 `./final_check.md`，整体通读，输出最终版本。
