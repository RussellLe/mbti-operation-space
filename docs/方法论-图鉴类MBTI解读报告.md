# 方法论：图鉴类 MBTI 角色分析报告

> 基于角色的 MBTI 类型定型和剧情材料，输出兼具理论深度与叙事力量的角色分析报告。

---

## 一、任务定义

**输入**：
- 角色 MBTI 类型表（角色名 + 四字母类型 + 功能栈）
- MBTI 八维认知功能知识库（每个功能的含义、核心倾向、使用特征、典型场景）
- 角色剧情材料（剧情摘要、名场面整理、台词等）

**输出**：
- 每个角色一份分析，包含两个模块：
  - **功能栈解读**（4段）：主导、辅助、第三、劣势功能各一段
  - **总结**（1段）：脱离 MBTI 视角的角色叙事

---

## 二、执行步骤

### Step 1：通读全部材料，建立角色认知

先完整阅读剧情材料，为每个角色建立以下心理模型：

- 这个角色的**核心驱动力**是什么？（如：守护家人、复仇、夺权、活下去）
- 这个角色的**行为模式**是什么？（如：先行动后思考、隐忍克制、情绪操控）
- 这个角色的**关键转折点**有哪些？（如：身份揭露、信念动摇、关系破裂）
- 这个角色让观众记住的**标志性瞬间**是什么？

> **原则**：先理解人，再套理论。不要拿着功能栈去找证据，而是先理解角色，再用功能栈解释"为什么他会这样做"。

### Step 2：确认功能栈，理解四个功能的角色

根据 MBTI 类型查出功能栈（主导-辅助-第三-劣势），理解每个功能在该位置上的含义：

| 位置 | 功能角色 | 写作定位 |
|------|----------|----------|
| 主导 | 核心驱动力，最自然的行为模式 | 写"这个人本能上是怎样运作的" |
| 辅助 | 补充和平衡主导功能 | 写"主导功能做完判断后，他用什么方式执行/补充" |
| 第三 | 不成熟但在发展中的功能 | 写"他在哪些时刻会显出不那么典型的一面" |
| 劣势 | 最不受控、压力下暴露的弱点 | 写"他在什么情况下会失控/暴露短板" |

### Step 3：为每个功能匹配剧情证据

从剧情材料中，为每个功能找到 2-3 个具体场景作为论据。匹配规则：

- **主导功能**：找角色**最高频**的行为模式，尤其是在不同情境下重复出现的反应方式
- **辅助功能**：找角色**做完第一反应之后的第二步动作**，通常体现为"判断后如何执行"或"行动后如何评估"
- **第三功能**：找角色偶尔显露的**反差面**或**成长弧线**中的变化
- **劣势功能**：找角色**失控、犯错、暴露弱点**的场景

> **关键判断**：同一个剧情场景可能同时体现多个功能，选择该场景中**最核心的认知过程**来归类。例如：一个角色在危机中冷静分析后迅速行动——"冷静分析"归 Ti/Te，"迅速行动"归 Se。

## 三、产出要求

### 3.1 功能栈解读段（每角色 4 段）

**格式**：

```
**主导 XX（功能全称）**：[论述文字]
**辅助 XX（功能全称）**：[论述文字]
**第三 XX（功能全称）**：[论述文字]
**劣势 XX（功能全称）**：[论述文字]
```

**字数**：每段 80-140 字（中文字符计），最佳区间为 100 字左右。

**写作规则**：

1. **「剧情先行，理论收束」**：每段以具体剧情场景开头或贯穿，用理论语言做结尾归纳。禁止先写一段理论定义再附上剧情例子。

   ```
   ✗ "Se 的核心是即时感官反应。樊长玉在雪地救人时就体现了这一点。"
   ✓ "雪地救人时即刻判断伤情、藏谢征进猪棚时利用屠户身份应付官差——她永远在用身体先于思考做出反应。"
   ```

2. **「动词驱动」**：用角色的具体动作和选择来展现功能，而非用形容词贴标签。

   ```
   ✗ "他是一个很有洞察力、很有远见的人。"
   ✓ "以'言正'身份潜伏时，他早已看穿樊家被袭与十七年前旧案的关联。"
   ```

3. **「功能间建立关联」**：辅助、第三、劣势功能的论述应与主导功能形成呼应或张力，让四段读下来构成一个完整的认知画像。

   ```
   示例（INTJ）：
   - 主导 Ni 写"他看到了什么"
   - 辅助 Te 写"他如何把看到的变成行动"
   - 第三 Fi 写"他在情感面前如何失去冷静"
   - 劣势 Se 写"他在什么时候彻底失控"
   ```

4. **「反派/负面角色的功能不美化」**：认知功能本身中性，但在特定角色身上可能表现为扭曲、极端或病态的形式。如实描写这种扭曲，不要为了"客观"而洗白。

   ```
   示例：Fe 在正面角色身上是"共情与维护集体氛围"，在操控型反派身上就是"读懂他人情绪后加以玩弄"。
   ```

5. **「劣势功能不要只写弱」**：劣势功能是角色最大的成长空间，也是压力下最生动的反应。写出"弱在哪里"的同时，写出"弱的时候是什么样子"甚至"弱势功能在关键时刻如何以另一种形式爆发"。

6. **「每段至少包含 2 个具体剧情场景」**：不能只用一个例子支撑整段论述。多场景交叉印证才能说明这是角色的稳定模式而非孤立事件。

### 3.2 总结段（每角色 1 段）

**字数**：100-160 字（中文字符计）。

**职能**：让不了解这个角色的读者迅速"认识"他，让了解的读者产生共鸣。总结段是**叙事**，不是**分析**，更不是功能栈解读的自然语言翻译。

#### 内容要素（按顺序）

总结段应依次覆盖以下四个要素（不必机械分段，应融为一体的叙事）：

1. **角色的核心台词或信念宣言**（作为开篇引文）
   - 选择标准：能代表角色核心信念、有情感冲击力、读者即使不了解剧情也能被触动
   - 如果角色没有足够有力的台词，可用一个标志性动作/瞬间替代

2. **角色的身世和处境**（一两句话交代背景）
   - 让不了解剧情的读者快速建立基本认知
   - 不要写成百科词条式的生平介绍，要有情感温度

3. **角色最具辨识度的行为或选择**（让读者"看见"这个人）
   - 用 2-3 个关键瞬间串联，展现角色的行为模式和内在逻辑
   - 这些瞬间应能体现人物弧线的跨度——从起点到终点的变化或一贯性

4. **角色的终极价值取向**（点题/收束）
   - 用一句有力度的话收束，适合被单独截图传播
   - 可以是感慨、定性、或一个意味深长的事实

#### 写作规则

1. **「叙述节奏要有起伏」**：从低处（普通人/少年/困境）写到高处（信念/牺牲/选择），让读者感受到人物弧线的张力。不要平铺直叙。

   ```
   示例（从低到高）：
   "樊家供他读书、等他考功名，他考中那天翻脸退了婚。后来长玉落难，他上门提纳妾……
    被革职那晚他抱着酒壶叹苍天不公——从头到尾没觉得是自己的问题。"
   ```

2. **「用场景开头，不用判断句开头」**：

   ```
   ✗ "樊长玉是一个坚韧不拔、重情重义的女性角色。"
   ✗ "樊长玉的力量不来自谋略或天赋，而来自一种近乎本能的不肯后退。"
   ✓ "孤山军营重逢，满身血污的谢征站在她面前，她脱口而出的不是什么深情告白，而是'我杀猪养你'。"
   ```

3. **「用角色自己的动作和选择说话」**：不要替角色总结性格，而是摆出关键行为/瞬间，让读者自己感受到"这是一个什么样的人"。

   ```
   ✗ "他是一个极度隐忍、善于谋划的人。"
   ✓ "他藏了太多年——藏身份、藏仇恨、藏那些不能说的话。谢氏陵前挨完一百零八鞭，他没改心意。"
   ```

4. **「收束句要有力度」**：最后一句是整段的落点，应具备独立传播的力量——从上下文中摘出来，读者也能被击中。

   ```
   示例：
   "李怀安不是最锋利的人，但他从来没弯过。"
   "那大概是他这辈子唯一一次没有算计的动作。"
   "他就是那种人：你穷时他嫌你，你好时他悔，你不理他了，他怪老天爷。"
   ```

5. **「禁止出现 MBTI 术语」**：总结段中不得出现任何 MBTI 类型代码（如 INTJ）、认知功能名称（如 Ni、Se）、或理论术语（如"功能栈""主导功能"）。

6. **「语言风格：白话叙事，不要书面腔」**：语感应接近"一个很懂这部剧的朋友跟你聊某个角色"，而非学术论文或产品说明书。允许口语化表达、短句、省略句。

### 3.3 整体结构格式

```markdown
## N）角色名 · MBTI类型（功能栈）

**主导 XX（功能全称）**：……

**辅助 XX（功能全称）**：……

**第三 XX（功能全称）**：……

**劣势 XX（功能全称）**：……

**总结**：……
```

- 角色间用 `---` 分隔
- 文档开头用一级标题标注作品名

## 四、底层规则

以下规则适用于所有角色、所有类型，是产出质量的底线保障。

### 规则 0（最高优先级）：文案的本质是"用故事证明性格"，不是"用逻辑论证类型"

这是本文档的第一性原理，统摄所有后续规则。

分析报告的任务是论证，文案的任务是**感染**。读者不需要知道认知功能栈是什么，他们需要的是：读完之后觉得"这个人确实是这样的"。

```
❌ 分析报告式写法："他的愤怒触发点指向道德信念被践踏而非利益受损，
   这是 F 型价值判断体系的典型激活模式"
✅ 文案式写法："何承训拿恩师人头来邀功，他一刀下去，
   转头带着哭腔崩溃：'令公还要立我为国主吗？'"
```

**底层逻辑**：让读者通过一个具体场景自行得出"这个人是情感驱动的"这个结论，比你直接告诉他有效十倍。

这一原则同时适用于功能栈解读和总结段：
- **功能栈解读**中，理论术语可以出现，但它的角色是"标注"而非"主角"——剧情场景才是主角，术语只是帮读者知道"这段在说哪个功能"
- **总结段**中，理论术语完全禁止出现，纯粹用故事说话

### 规则 1：认知功能是"过程"，不是"结果"

认知功能描述的是一个人**如何感知和判断信息**，而不是他**做了什么事**或**是什么样的人**。

```
✗ "Te 让他成为了领导者。"（这是结果）
✓ "他接手混乱的项目后，迅速梳理出关键节点、分配资源——这是 Te 在组织外部逻辑。"（这是过程）
```

### 规则 2：同一类型不同角色，写出的东西必须不同

MBTI 类型相同的角色，功能栈解读不能雷同。相同的功能在不同角色身上，因为人生经历、价值观、所处环境的不同，会有截然不同的表现。

```
示例：同为 ISFJ 的宋砚和李怀安——
- 宋砚的 Si 表现为"对阶层提升的精密盘算，把恩情当可以翻篇的旧账"
- 李怀安的 Si 表现为"稳扎稳打地兜底，用经验把每件事做到位"
同一个功能，完全不同的人。
```

### 规则 3：功能栈解读不做价值判断，总结段可以

功能栈解读段应保持"分析师"视角——客观展示认知过程如何运作，即使是反派的扭曲行为也用中性语言描述其认知机制。

总结段则可以、也应该带有对角色的**理解和态度**——同情、唏嘘、敬佩、或冷静的审视。这正是总结段区别于功能栈解读的核心。

### 规则 4：剧情论据必须具体到"场景级"

```
✗ "她很勇敢，多次在危险中保护他人。"（模糊）
✓ "大伯上门抢房契时她提棍拦在门前，妹妹哮喘发作后她瞬间翻脸，一步不退。"（场景级）
```

每个功能解读至少用 2 个场景级论据支撑。如果在材料中找不到足够的场景，说明该功能的判定可能需要重新审视，而不是用模糊描述凑数。

### 规则 5：破句式 > 长句

控制单句长度，优先用破折号、分号、短句连缀来制造节奏感。避免从句套从句的学术式长句。

```
✗ "他是一个在面对各种复杂局势时始终能够保持冷静并做出精确判断的人，这使得他在多次危机中都能够化险为夷。"
✓ "他教长玉学法条、布水淹之计救人、戴面具登城平乱——每一步都是将内心判断转化为精密可操作的方案。"
```

### 规则 6：不要为了理论完整性而强行解读

如果某个功能在剧情材料中缺乏足够证据，宁可写短、写少，也不要编造或过度推演。可以诚实地写"该功能在剧情中表现不显著"或从角色的"缺失感"入手（如"他从未表现出对XX的关注，这本身就是该功能弱势的佐证"）。

## 五、常见陷阱

### 陷阱 1：功能栈解读写成了性格描述

```
✗ "她是一个热情、善良、勇敢的人。"
```

这是性格标签，不是认知功能分析。功能分析的核心问题是"她**如何**感知外界、**如何**做出判断"，而非"她是什么样的人"。

### 陷阱 2：总结段写成了功能栈的自然语言翻译

```
✗ "综上所述，她的核心驱动力是即时感知外界并做出快速反应，内心有坚定的价值观，在被逼到绝处时能组织资源解决问题，但缺乏长远规划能力。"
```

这只是把四段功能栈解读拼在一起换了个说法。总结段应该是一个**全新的文本**，用叙事手法讲述"这个人是谁"。

### 陷阱 3：所有角色的劣势功能都写成"在压力下失控"

劣势功能的表现远不止"失控"。它可以是：
- 长期回避某类情境（如 Fi 劣势的人回避面对自己的真实感受）
- 笨拙但努力地使用（如 Ne 劣势的人在需要变通时显得僵硬）
- 被他人轻易击中的软肋（如 Se 劣势的人在需要即时反应时慢半拍）
- 关键时刻以粗糙但有力的方式爆发（如 Ni 劣势的人偶尔凭直觉做出正确但无法解释的决定）

### 陷阱 4：正面角色的功能全写成优点，反面角色的功能全写成缺点

每个功能都是中性的认知工具。正面角色也会因为主导功能的过度使用而犯错（如 Se 主导者的冲动），反面角色的主导功能也可能表现出令人印象深刻的能力（如操控型角色对 Fe 的高超运用）。保持如实描写。

## 六、质量校验清单

### 功能栈解读段
- [ ] 每个角色的功能栈顺序与其 MBTI 类型一致（无功能位置错误）
- [ ] 每段包含至少 2 个具体剧情场景（场景级论据，非模糊描述）
- [ ] 每段在 80-140 字之间
- [ ] 剧情场景是主角、理论术语是标注——不存在"先讲理论再举例"的段落
- [ ] 同一 MBTI 类型的不同角色，论述内容无雷同
- [ ] 反派角色的功能描写如实呈现扭曲使用，未刻意美化或丑化
- [ ] 全文无"性格贴标签"式的空洞描述（如"他很聪明""她很坚强"）

### 总结段
- [ ] 不包含任何 MBTI 术语（类型代码、功能名称、理论术语）
- [ ] 以场景/台词/具体行为开头，而非判断句或分析句
- [ ] 覆盖四要素：核心台词或信念 → 身世处境 → 标志性行为 → 终极价值取向
- [ ] 叙述节奏有起伏（从低处到高处，能感受到人物弧线）
- [ ] 收束句有力度，具备脱离上下文独立传播的能力
- [ ] 不是功能栈解读的自然语言翻译——是一个全新的叙事文本
- [ ] 语言风格为白话叙事，非书面腔/学术腔

### 整体
- [ ] 通读全文后，即使不懂 MBTI 的读者也能感受到每个角色的独特性
- [ ] 通读全文后，读者的感受是"被故事打动了"而非"被科普了一遍理论"
