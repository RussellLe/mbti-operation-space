# 影视角色 MBTI 社交媒体文案生成方法论

> 适用场景：基于已完成的 MBTI 性格分析报告，生成一份可发布在小红书、抖音等社交媒体平台的角色性格解读文案。
>
> 前置依赖：需要一份完整的 MBTI 性格分析报告（参见《影视角色 MBTI 性格分析方法论》）。

---

## 一、核心原则

### 1.1 文案的本质是"用故事证明性格"，不是"用逻辑论证类型"

分析报告的任务是论证，文案的任务是感染。读者不需要知道认知功能栈是什么，他们需要的是：读完之后觉得"这个人确实是这样的"。

```
❌ 分析报告式写法："他的愤怒触发点指向道德信念被践踏而非利益受损，
   这是F型价值判断体系的典型激活模式"
✅ 文案式写法："何承训拿恩师人头来邀功，他一刀下去，
   转头带着哭腔崩溃：'令公还要立我为国主吗？'"
```

**底层逻辑**：让读者通过一个具体场景自行得出"这个人是情感驱动的"这个结论，比你直接告诉他有效十倍。

### 1.2 每个维度只选一个最强证据

分析报告中每个维度可能有 3-5 条证据。文案中只保留**说服力最强的那一条**——它需要同时满足两个条件：

1. **分析权重最高**：在原报告中被列为核心证据或综合判定中的关键依据
2. **画面感最强**：读者能在脑中"看到"这个场景，而非仅仅理解一个抽象概念

如果权重最高的证据画面感不足，优先选画面感强且权重不低的替代证据。社交媒体文案中，一个让人"看见"的场景胜过三个让人"理解"的论点。

### 1.3 用读者已有的直觉框架来锚定维度

MBTI 四个维度在大众心中有朴素理解。文案必须顺着这个直觉写，而非引入专业概念。

| 维度 | 读者的直觉理解 | 文案应传达的感觉 |
|------|---------------|----------------|
| I/E | 内向 vs 外向 | 这个人的能量从哪里来——是人群还是独处 |
| N/S | 远方与信念 vs 脚下与日常 | 这个人活在愿景里还是活在现实里 |
| F/T | 共情与情感 vs 理性与客观 | 这个人做决定时听心还是听脑 |
| J/P | 计划与坚定 vs 随性与灵活 | 这个人是锁定方向走到底还是边走边看 |

**禁止出现的专业术语**：认知功能栈、Ni/Ne/Si/Se/Fi/Fe/Ti/Te、主导功能、辅助功能、劣势功能、grip、内倾直觉、外倾情感等。

### 1.4 文案是提炼，不是缩写

"把分析报告缩短"和"从分析报告中提炼文案"是完全不同的操作。

```
❌ 缩写：删掉报告中的部分段落，保留剩余段落的原始措辞
✅ 提炼：理解报告的核心结论，用全新的、适合社交媒体阅读节奏的语言重新表达
```

## 二、关于示例的使用原则

本文档中的所有示例（包括第八节的完整示例）**仅作格式参考，绝对不能作为行文参照**。

示例展示的是：标题格式、引文格式、维度标签格式、段落结构、分隔线位置。

示例不代表：措辞风格、句式选择、叙事节奏、情感基调。

每个角色有独属于自己的场景和台词。文案必须从该角色的分析报告中提炼，用原始素材自然生长出语言，而非套用示例的行文框架。看到示例后仍按示例的句式仿写，是这一环节最常见的错误。

## 三、文案结构（格式要求）

文案分为两个部分，各有明确职能。

### 第一部分：角色概括（约 150 字）

**职能**：让不了解这个角色的读者迅速"认识"他，让了解的读者产生共鸣。

**内容要素**：
1. 角色的核心台词或信念宣言（作为开篇引文）
2. 角色的身世和处境（一两句话交代背景）
3. 角色最具辨识度的行为或选择（让读者"看见"这个人）
4. 角色的终极价值取向（点题）

**写法要求**：
- 开篇引文选择标准：能代表角色核心信念、有情感冲击力、读者即使不了解剧情也能被触动
- 叙述节奏要有起伏：从低处（普通人/少年/困境）写到高处（信念/牺牲/选择），让读者感受到人物弧线的张力
- 收束句要有力度，适合被单独截图传播

### 第二部分：四维度解读（每维度 40-60 字）

**职能**：用四个具体场景分别说明 I/N/F/J（或其他类型的四个维度），让读者直观感受"为什么是这个类型"。

**内容要素**：
- 每个维度配一个核心场景或行为细节
- 场景本身自带说服力，读者看完自然认同该维度判定

**写法要求**：
- 维度标签格式统一为 `**X 维度中文名｜**`，如 `**I 内向｜**`
- 每个维度段落内部完整讲述一个场景，禁止罗列多个片段
- 如果一个维度的最强证据是一段时间跨度较长的行为模式（如"二十年保护兄长"），用时间跨度本身来传达力度

## 四、文体禁令

以下写法在社交媒体文案中效果不佳或引发读者反感，严格禁止使用。

### 3.1 结构性禁令

| 禁止的结构 | 原因 | 示例 |
|-----------|------|------|
| 排比句 | 社交媒体文案中的排比容易显得刻意和空洞 | ❌ "他握得住刀，签得下字，扛得起天下" |
| 转折句（"不是A，而是B"）及其一切变体 | 过度使用会让文案读起来像辩论稿。变体包括但不限于："是A，不是B""A的是X，从来不是Y""挣扎的是A，从来不是B""从来不是A，而是B"——只要句子的逻辑结构是"肯定一侧、否定另一侧"，无论用什么词连接，都属于此类禁止结构 | ❌ "触发他的不是利益，而是人"<br>❌ "她挣扎的是怎么平衡代价，从来不是要去哪里"<br>❌ "触发他的从来是人，不是利益" |
| 对比句（"A却B""看似A实则B"） | 是转折句的变体，同样容易沦为套路 | ❌ "外界只看到结果，从未看到过程" |
| 引号造词 | 给普通词语加引号制造重点感是廉价修辞 | ❌ "他把'太平'刻进骨头" |

### 3.2 措辞禁令

| 禁止的措辞模式 | 替代方案 |
|--------------|---------|
| "别人都在A，只有他在B" | 直接写他在做什么，不需要用群体做反衬 |
| "从来是X""从来不是X""触发他的从来是……""他挣扎的从来不是……" | "从来"作副词修饰是非判断时，本质仍是在肯定一侧、否定另一侧，与"不是A而是B"同属转折结构。直接陈述他做了什么、他的选择是什么，不需要用"从来"来框定对立 |
| 连续三个以上"他"字开头的短句 | 变换句式主语，穿插场景描写或直接引用台词 |
| 抽象形容词堆叠（"坚定的、温柔的、不屈的"） | 用一个具体场景代替三个形容词 |
| 感叹号 | 文案的力度来自内容本身，不来自标点 |

### 3.3 自查方法

写完文案后，逐句执行以下检查：

```
□ 这句话删掉后，文案是否损失了信息量？（如果没有 → 删掉）
□ 这句话能否被替换成一个具体场景？（如果能 → 替换）
□ 这句话是否依赖某种句式结构来制造效果？（如果是 → 重写，让内容本身承载效果）
□ 这句话里的引号是否引用的是真实台词/文献？（如果不是 → 去掉引号）
□ 这句话是否出现了排比/转折/对比结构？（如果是 → 重写）
□ 这句话是否含有"从来是""从来不是""挣扎的是A从来不是B"等用"从来"修饰的是非判断？（如果是 → 重写，删掉是非框架，直接陈述行为）
```

## 五、执行步骤

### 步骤 1：阅读分析报告，提取核心素材；读取同剧已有文案，标记回避词库

**操作**：

1. 通读完整分析报告
2. 为每个维度标记出：
   - 综合判定中被列为关键依据的证据（权重最高）
   - 所有证据中画面感最强的一条
3. 标记出角色的核心台词（从报告引用的台词中选取最具冲击力的 1-2 句）
4. 标记出角色最具辨识度的身份/行为特征
5. **读取 `result/` 目录中所有与本剧同名前缀的已有文案**（如当前剧名为"太平年"，则读取所有 `太平年-*-文案.md`），提取其中出现的：
   - 各维度段落的收束句
   - 角色概括段的收束句
   - 任何带有概括性、判断性的短句（尤其是对角色性格的总结表述）
   - 将上述内容汇总为**回避词库**，写入素材清单

**产出**：一份包含以下内容的素材清单——

```
核心台词：[1-2句]
角色辨识度特征：[1-2个]
I/E 最强证据：[1条，附场景细节]
S/N 最强证据：[1条，附场景细节]
T/F 最强证据：[1条，附场景细节]
J/P 最强证据：[1条，附场景细节]
同剧回避词库：[从已有文案中提取的收束句、判断句，本文案不得复用]
```

### 步骤 2：撰写第一部分（角色概括）

**操作**：

1. 以核心台词作为开篇引文
2. 用 1-2 句话交代角色的身世和处境
3. 选取最能代表角色的一个行为或选择展开描写
4. 用一句收束句点题

**关键检查**：
- 一个完全不了解这部剧的读者，能否通过这段文字对角色产生兴趣？
- 概括部分是否有一句话值得被单独截图？

### 步骤 3：撰写第二部分（四维度解读）

**操作**：

1. 对步骤 1 中选出的四条最强证据，逐条用文案语言重写
2. 每条控制在 40-60 字
3. 为每条配上维度标签

**关键检查**：
- 每段是否完整讲述了一个场景，而非罗列碎片？
- 读者读完每段后，是否自然认同该维度判定，不需要额外解释？
- 是否避开了所有文体禁令中列出的句式？

### 步骤 4：全文自查与修订

**操作**：

1. 执行 3.3 节的自查清单，逐句检查
2. 通读全文，检查阅读节奏——是否有某处读起来"卡顿"或"空洞"
3. 检查总字数是否在目标范围内（如有字数要求）
4. **对照步骤 1 建立的同剧回避词库，逐句核查**：是否有任何一句话（尤其是收束句和判断句）与同剧已有文案在**表达的核心判断**上相近——即使用词不同，若传达的是同一个"角色性格结论"，也属于重复，需重写
5. 最终确认：这篇文案是否让读者"感受到"了这个角色的性格，而非仅仅"知道"了他的 MBTI 类型

## 六、底层规则

### 规则 1：具体场景 > 抽象概括

这是文案写作的第一原则。任何时候，如果你面临"写一个抽象总结"和"写一个具体场景"的选择，选后者。

```
❌ "他是一个内心坚定的人"
✅ "胡进思逼他杀七哥，他顶了整整二十年"
```

前者告诉读者一个结论，后者让读者自己得出结论。后者的说服力远大于前者。

### 规则 2：台词引用是最高效的人物刻画手段

一句好的台词引用能同时完成三件事：展现性格、推进叙事、制造情感冲击。在文案中，真实台词的密度应当高于描述性文字。

**选择台词的标准**：
- 脱离剧情语境后仍然有力（读者不需要知道前因后果就能被打动）
- 能直接指向某个 MBTI 维度的特征
- 有口语感，适合社交媒体传播

### 规则 3：文案的情感力度来自克制，不是来自渲染

越想让读者感动，越要克制你的措辞。堆砌形容词和感叹号会稀释情感浓度。

```
❌ "他承受了多么巨大的痛苦啊！这份坚守令人无比动容！"
✅ "胡进思逼他杀七哥，他顶了整整二十年。"
```

事实本身的重量已经足够。你的工作是把事实摆出来，不是替读者做情感反应。

### 规则 4：每一句话都要承载信息增量

社交媒体用户的注意力极其有限。文案中不能有"过渡句""氛围句"或"为了好听而存在的句子"。每一句话要么提供新信息，要么推进叙事，要么制造情感转折。不满足其中任何一条的句子，删掉。

### 规则 5：维度解读段的最后一句话决定说服力

每个维度段落的最后一句话是读者记住的东西。它应当是一个**从场景中自然生长出来的判断**，而非一个贴上去的标签。

```
❌ 场景描写之后接 → "这就是典型的F型人格特征。"
❌ 场景描写之后接 → "由此可见他是情感驱动的。"
✅ 场景描写之后接 → "触发他的从来都是具体的人。"（从场景中自然提炼的判断）
```

### 规则 6：禁止在文案中解释 MBTI 理论

读者不需要知道什么是认知功能栈，不需要知道 Fe 和 Fi 的区别，不需要知道 grip 现象。文案的任务是让读者认同"这个角色是 XXXX 型"，手段是场景和细节，不是理论解释。

## 七、质量检查清单

文案完成后，用以下清单逐项检查：

| 检查项 | 通过标准 |
|--------|---------|
| 文体禁令 | 全文无排比、无"不是A而是B"转折、无引号造词、无"别人都A只有他B" |
| 专业术语 | 全文无 MBTI 专业术语（认知功能、Ni/Fe/Ti/Se 等） |
| 场景具体性 | 四个维度的解读段均包含至少一个可视化的具体场景 |
| 信息密度 | 全文无纯过渡句或纯氛围句，每句话承载信息增量 |
| 台词引用 | 所有引号内的内容均为角色真实台词或文献原文 |
| 维度锚定 | 四个维度的解读段均能让不懂 MBTI 的读者直观感受到该维度的含义 |
| 独立可读性 | 不了解该剧的读者能读懂并产生兴趣 |
| 收束句力度 | 第一部分的收束句适合被单独截图传播 |
| 同剧去重 | 全文所有收束句、判断句与同剧已有文案无实质重复——即使用词不同，传达同一个性格结论也算重复，需重写 |

## 八、经验总结

### 7.1 从分析报告到文案的信息压缩比

一份完整分析报告通常有 3000-5000 字，文案通常 300-500 字。压缩比约为 10:1。这意味着文案中的每一句话背后都应该有报告中大量论证的支撑。

**压缩的本质是选择，不是删减。** 你要做的决策是"用哪一个场景来代表这整个维度"，而不是"这段论述怎么缩短"。

### 7.2 最容易出问题的环节

| 环节 | 常见问题 | 应对方式 |
|------|---------|---------|
| 角色概括 | 写成了剧情简介 | 只保留能揭示性格的情节，删掉纯剧情推动的事件 |
| 维度解读 | 写成了分析报告的缩写版 | 重写，用场景叙事代替逻辑论证 |
| 收束句 | 用了空洞的形容词概括 | 回到角色的核心行为或台词，从中提炼 |
| 全文语气 | 变成了"我来告诉你他是什么性格" | 调整为"我把他的故事讲给你听，你自己感受" |

### 7.3 好文案的终极检验标准

**读者读完后的反应应该是"我懂他了"，而不是"我懂 MBTI 了"。**

文案的目标是让读者与角色产生情感连接，MBTI 类型只是组织这种连接的框架。如果读者记住了四个字母却忘了角色本身，文案就失败了。

## 九、输出文件格式规范

文案的最终产出是一个 Markdown 文件，该文件将被 `generate_poster.py` 脚本解析并自动生成小红书海报（HTML + PNG）。**必须严格遵守以下格式，否则脚本无法正确提取内容。**

### 8.1 文件命名

```
<剧名>-<角色名>-文案.md
```

- 使用半角连字符 `-` 分隔三个部分
- 第三段固定为 `文案`
- 脚本会从文件名提取剧名和角色名，用于海报标题显示
- 输出海报文件名为 `<剧名>-<角色名>.html` 和 `<剧名>-<角色名>.png`（自动去掉 `-文案` 后缀）

示例：`太平年-钱弘俶-文案.md` → 海报文件 `太平年-钱弘俶.html` / `太平年-钱弘俶.png`

### 8.2 文件结构（按顺序）

文件由以下五个部分组成，**顺序固定**：

```markdown
# <剧名>·<角色名> | <MBTI四字母> <MBTI中文名>

**"<角色核心台词>"**

<角色概括段落1>

<角色概括段落2（收束句，独占一段）>

---

**<字母> <维度中文名>｜** <该维度的场景描写>

**<字母> <维度中文名>｜** <该维度的场景描写>

**<字母> <维度中文名>｜** <该维度的场景描写>

**<字母> <维度中文名>｜** <该维度的场景描写>
```

### 8.3 各部分格式详解

#### 1) 标题行

```markdown
# 太平年·钱弘俶 | INFJ 提倡者
```

- 必须是一级标题（`#` 开头）
- MBTI 四字母必须为大写，且是合法组合（`[IE][NS][FT][JP]`）
- 四字母与中文名之间用空格分隔；脚本通过正则 `INFJ[\s·]+提倡者` 提取中文名
- 中文名不要带括号或其他标点

#### 2) 引文行

```markdown
**"是非是有的，一定是有的。千秋史册在上，江山黎庶在下，此事万古不易。"**
```

- 整行用 `**` 加粗包裹
- 引文内容以中文左双引号 `"` 或左书名号 `「`/`『`/`《` 开头
- 脚本通过加粗 + 引号开头的组合来识别此行，提取后去掉首尾 `**`
- 如果角色没有合适的核心台词，此行可省略（海报上将不显示引文区块）

#### 3) 角色概括段落

标题行、引文行、分隔线 `---`、维度行之外的所有非空行，都会被脚本收集为角色概括文本。

- 概括内容可以是一段或多段，段落之间用空行分隔
- **最后一个概括段落**会被脚本单独提取为高亮收束句，在海报上以醒目样式呈现
- 因此收束句必须独占最后一个自然段，不要和前文连在同一段内

#### 4) 分隔线

```markdown
---
```

- 在角色概括与维度解读之间放置一条分隔线
- 脚本会跳过此行

#### 5) 维度解读行

```markdown
**I 内向｜** 他说自己就是个渔账子。坐拥吴越半壁江山的国主，心底认同的身份是市井里做鱼脍的少年。
```

格式要求（每个字符都有意义，不可随意变动）：

| 组成部分 | 格式 | 说明 |
|---------|------|------|
| 加粗开始 | `**` | 固定 |
| 维度字母 | `I` / `E` / `N` / `S` / `F` / `T` / `J` / `P` | 大写单字母 |
| 空格 | ` ` | 字母与中文名之间有一个半角空格 |
| 维度中文名 | `内向` / `外向` / `直觉` / `实感` / `情感` / `逻辑` / `判断` / `感知` | 固定用词，见下表 |
| 分隔符 | `｜` | **全角**竖线（U+FF5C），不是半角 `|` |
| 加粗结束 | `**` | 固定 |
| 空格 | ` ` | 加粗结束后跟一个半角空格 |
| 描写内容 | 自由文本 | 该维度的场景描写 |

维度中文名对照表（必须使用以下固定用词）：

| 字母 | 中文名 | 英文名 |
|------|--------|--------|
| I | 内向 | Introverted |
| E | 外向 | Extraverted |
| N | 直觉 | Intuitive |
| S | 实感 | Sensing |
| F | 情感 | Feeling |
| T | 逻辑 | Thinking |
| J | 判断 | Judging |
| P | 感知 | Perceiving |

- 四个维度行的顺序应与 MBTI 四字母顺序一致（如 INFJ → I, N, F, J）
- 每个维度行独占一行，不要折行
- 维度行之间用空行分隔

### 8.4 完整示例

```markdown
# 太平年·钱弘俶 | INFJ 提倡者

**"是非是有的，一定是有的。千秋史册在上，江山黎庶在下，此事万古不易。"**

五代十国，礼崩乐坏。十二岁混迹市井做鱼脍的少年，被命运推上王座之后，拉不开弓，打不赢仗。但他用一种近乎笨拙的温柔扛住了一整个乱世，最后亲手终结了自家的王朝——"吾不忍以一姓之荣，陷万民于水火。"

太平年三字，他拿一生的血泪写就。

---

**I 内向｜** 他说自己就是个渔账子。坐拥吴越半壁江山的国主，心底认同的身份是市井里做鱼脍的少年。史载他口不辍诵佛经，自奉极薄，食不重味。权力的聚光灯打在他身上，他的能量却始终向内生长。

**N 直觉｜** 帮赵匡胤灭南唐，满朝都喊唇亡齿寒。他已经看到了天下终将一统的走向，剩下的问题只有流多少血。所有人盯着眼前的棋局，他盯着棋局之外的那个终局。

**F 情感｜** 何承训拿恩师人头来邀功，他一刀下去，转头带着哭腔崩溃："令公还要立我为国主吗？"胡进思逼他杀七哥，他顶了整整二十年。他可以忍住权臣的羞辱去做长线博弈，却在有人践踏他珍视的生命时瞬间失控。触发他的从来不是利益，是人。

**J 判断｜** 瓦解胡进思的权力，他花了两年。先给荣衔稳住局面，再暗中拆分禁军编制，最后等时机成熟收网。全程保持同一个战略方向，没有一步走偏。白宇说得准确——他挣扎的从来是怎么平衡代价，方向本身从未松动过。
```

### 8.5 格式自查清单

| 检查项 | 通过标准 |
|--------|---------|
| 文件命名 | `<剧名>-<角色名>-文案.md`，半角连字符分隔 |
| 标题行 | `#` 开头，包含合法的四字母 MBTI 代码（大写）和中文名 |
| 引文行 | `**` 包裹，以中文引号或书名号开头；或整行省略 |
| 收束句 | 独占角色概括的最后一个自然段 |
| 分隔线 | 概括与维度之间有 `---` |
| 维度行格式 | `**X 中文名｜**` 使用全角竖线，中文名使用固定用词 |
| 维度行数量 | 恰好 4 行，与 MBTI 四字母一一对应 |
| 无多余标记 | 除标题 `#`、加粗 `**`、分隔线 `---` 外，不使用其他 Markdown 标记（无列表、无代码块、无二级标题等） |
