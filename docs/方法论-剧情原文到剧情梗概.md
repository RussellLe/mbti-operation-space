# 方法论：从剧情原文提炼 MBTI 剧情分析材料

## 任务定义

**输入**：
- **剧情原文**：小说原文、影视解说稿、剧评合集等包含具体情节的原始文本。这类素材通常来源杂、质量参差，存在重复叙述、名字错漏、视角混杂等问题。
- **用户指定的双主角**：两个需要重点分析的角色名字
- **用户指定的 MBTI 类型**：两个角色各自的 MBTI 四字母类型（如 ESFP、INTJ）
- **MBTI 八维知识库**：`skills/mbti-8wei/SKILL.md` 中的认知功能定义和 16 型功能栈

**输出**：一份结构化的 MBTI 剧情分析材料文档（如 `樊长玉X谢征-剧情分析材料.md`），包含引言、约 20 个核心桥段的剧情简述与八维功能解析、结语。

**核心定位**：这份材料是整个 MBTI 内容生产流水线的基础素材。它同时服务于后续的"分段解读"、"短诗创作"、"共鸣文案"等多个下游任务。因此它需要做到两件事：第一，把散乱的原始剧情提炼成清晰、准确、有细节的桥段简述；第二，为每个桥段标注准确的认知功能分析，建立剧情与 MBTI 理论之间的映射关系。

---

## 执行步骤

### Step 0：建立角色的八维功能面板

在动笔之前，先根据用户给出的两个 MBTI 类型，查阅知识库中的功能栈表，写出两个角色的完整八维排列。

**操作方法**：
1. 从知识库的 16 型功能栈表中查出两个类型的 1st-8th 功能
2. 标注每个功能的位置含义（主导、辅助、第三、劣势、阴影）
3. 对照知识库中每个功能的详细定义，理解它在不同位置上的表现差异

**示例**：
```
樊长玉 ESFP：Se(主导) - Fi(辅助) - Te(第三) - Ni(劣势) | Se-Fi-Te-Ni
谢征   INTJ：Ni(主导) - Te(辅助) - Fi(第三) - Se(劣势) | Ni-Te-Fi-Se
```

在这一步就应该注意到两个类型之间的结构关系。上面这组是完全逆位排列（ESFP 的主导是 INTJ 的劣势，反之亦然），这是后续分析的重要线索。

**为什么这步很重要**：整个分析过程中，你需要反复判断"这段剧情里角色在用哪个功能"。如果你对两个角色的功能面板不熟悉，判断就会出错或含糊。这一步是在给自己装上分析的"透镜"。

### Step 1：通读原文，建立事件清单

#### 1.1 处理原始素材的质量问题

剧情原文通常不是一个干净的、线性的叙事。它可能是多段视频解说的拼接、多篇剧评的合集，甚至包含弹幕风格的碎片文字。在通读之前，你需要对素材的特征有预判：

**常见问题及处理方式**：

| 问题 | 表现 | 处理方式 |
|------|------|----------|
| 名字不统一 | 同一角色出现多种写法（如"凡常玉""樊长玉""常玉""常煜"） | 通读时统一识别，在输出中使用正确名字 |
| 事件重复叙述 | 同一件事被不同段落从不同角度讲了两三遍 | 合并为一条事件记录，保留各版本中独有的细节 |
| 视角混杂 | 一段文字既写主角也写配角，跳来跳去 | 只提取与指定双主角相关的内容 |
| 时间线混乱 | 倒叙、插叙、预告交错 | 通读时梳理出正确的时间线顺序 |
| 事实错误 | 解说者张冠李戴、记错情节 | 以多段素材交叉验证，取最合理的版本 |

#### 1.2 提取事件

通读全文，提取所有涉及指定双主角的事件。每个事件记录以下信息：

```
事件编号：_
事件名称：[一个短标题，如"雪夜捡人"]
涉及角色：[哪些角色参与]
发生阶段：[在整体故事中的大致位置：相识期 / 相处期 / 分离期 / 重逢期 / 高潮期 / 收束期]
事件概要：[2-3 句话写清楚发生了什么]
关键细节：[原文中的具体言行、场景描写、台词]
角色动机：[每个角色为什么这么做]
情感变化：[这件事对两人关系产生了什么影响]
```

**注意**：这一步是"忠实记录"，不需要做 MBTI 分析。先把原始素材里有什么搞清楚，再考虑怎么用。

#### 1.3 处理配角相关内容

原始素材中通常包含大量配角的剧情线（如反派内斗、配角感情线、背景势力博弈等）。处理原则：

- 如果配角事件直接影响了双主角的行为或关系变化，保留并简要记录其因果关系
- 如果配角事件是独立的子线，与双主角无直接关联，跳过
- 如果配角事件提供了理解双主角行为的必要背景，简要记录背景信息即可

### Step 2：筛选核心桥段

从事件清单中筛选约 20 个核心桥段。这一步是整个流程中判断力要求最高的环节。

#### 2.1 筛选标准

一个事件要入选核心桥段，至少要满足以下三个条件中的两个：

**条件 A：认知功能可读性高**
这段剧情中，至少一个角色的某项认知功能有明确、具体、可描述的表现。"明确"意味着不需要过度推测就能判断他在用哪个功能；"具体"意味着功能的表现落在了一个具体的行为上，而非模糊的态度或氛围。

**条件 B：关系推进价值大**
这段剧情在两人关系的发展弧线上构成了一个节点。它可以是转折点（从不信任到信任）、冲突点（价值观碰撞）、融合点（彼此理解加深），或是关系定义的关键时刻（如身份揭露、承诺、决裂）。

**条件 C：功能互动有张力**
这段剧情中，两个角色的认知功能之间产生了碰撞、互补、代偿、或失控。例如 ESFP 的 Se 即时反应与 INTJ 的 Ni 深思熟虑在同一事件中产生了对照；或者一方的劣势功能在极端情境下被迫启动。

#### 2.2 覆盖性检查

筛选完成后，做以下覆盖性检查：

**故事弧线覆盖**：20 个桥段是否覆盖了从相识到结局的完整弧线？每个阶段（相识、相处、分离、重逢、高潮、收束）至少有 2-3 个桥段？如果某个阶段空白，回到事件清单补选。

**功能覆盖**：两个角色的前四项功能（主导、辅助、第三、劣势）是否都至少出现了一次？特别检查：
- 劣势功能是否有至少一个爆发场景？
- 第三功能是否有展示？
- 两个角色的主导功能是否都有多次、多角度的呈现？

**关系维度覆盖**：20 个桥段是否涵盖了以下关系维度中的大部分？
- 日常相处中的性格摩擦与互补
- 危机中的本能反应差异
- 情感表达方式的错位与对接
- 价值观冲突与理解
- 信任的建立与破裂
- 各自的成长与改变

#### 2.3 排序

将筛选出的桥段按故事的时间线排序。如果有些桥段在时间线上位置模糊，按关系发展的逻辑排序。

### Step 3：为每个桥段撰写剧情简述

#### 3.1 信息密度

每个桥段的剧情简述控制在 2-4 句话。在这个篇幅内需要完成三件事：

1. **交代前因**：为什么会发生这件事（1 句话以内）
2. **描述事件**：具体发生了什么（1-2 句话）
3. **点出关键细节**：角色做了什么具体的事、说了什么具体的话（融入上面的描述中）

#### 3.2 细节的选择

从原文中挑选哪些细节写进简述，遵循一个原则：**选那些能直接反映认知功能的细节**。

比如写"雪夜捡人"这个桥段：
- "她把他背回了家"——体现 Se 的身体本能反应
- "一碗热汤"——体现 Se 的即时务实行动
- "毫不犹豫"——体现 Fi 的价值驱动（见死不救不行）

不需要写进简述的细节：天气有多冷、她走了多远的路、她之前在做什么。除非这些细节直接关联认知功能分析。

#### 3.3 文字要求

- 用第三人称叙述
- 写具体的动作和台词，少用概括性描述
- 保持中性视角，不在简述中加入情感评价或分析性判断
- 角色名字统一，使用正确写法

**示例**：
```
面对街坊邻居关于她"克死爹娘"的恶毒流言，樊长玉没有任何内耗与自证，
直接端起一盆腥臭的猪血水泼向造谣者。
```

### Step 4：为每个桥段撰写八维功能解析

这是整份材料最核心、也最容易写偏的部分。

#### 4.1 确定分析焦点

每个桥段的分析应聚焦于 1-2 个认知功能的具体运作。在动笔之前回答三个问题：

1. **这段剧情中，哪个角色的哪个功能被激活得最明显？** 选它做主焦点。
2. **这个功能是在什么状态下运作的？** 常态运作（日常使用优势功能）、协同运作（两个功能联动）、还是极端激活（劣势功能在压力下爆发）？
3. **功能激活后，角色做了什么可观察的行为？** 这个行为就是分析的锚点。

将焦点标注在桥段标题旁边，如：`（ESFP Se-Te 联动）`、`（INTJ Fi 压倒 Ni）`。

#### 4.2 分析的写法

每段分析的结构是：**先指出角色做了什么，再解释这背后是哪个功能在运作，最后说明这个功能在此情境下的独特表现**。

具体要做到：

**a. 功能判断要有依据**

说角色在用某个功能，必须能指向一个具体的行为或决策。不能因为角色是 ESFP 就默认他任何时候都在用 Se。需要说明：他做了什么事 → 这件事的特征符合哪个功能的定义 → 所以判断他在用这个功能。

**b. 区分功能位置的差异**

同一个功能在不同位置上的表现是不同的。Se 作为 ESFP 的主导功能时，表现为自然流畅的感官敏锐度和即时反应能力；Se 作为 INTJ 的劣势功能时，平时被压抑，在极端情境下会以失控的、破坏性的方式爆发。分析时要体现这种位置差异。

**c. 写出功能之间的动态关系**

认知功能不是独立运作的。分析中应写出功能之间的协作或冲突：
- 主导与辅助的联动（如 Se 捕捉到信息，Fi 做出价值判断）
- 主导与劣势的冲突（如 Ni 的长线规划被 Se 的即时冲动打断）
- 一方的功能表现如何冲击了另一方（如 ESFP 的 Fi 真诚击穿了 INTJ 的 Ni 防备）

**d. 对照知识库，确保准确**

写每个功能的分析时，回到知识库检查：你对这个功能的描述是否符合知识库中的定义？是否混淆了相近的功能（如 Te 和 Ti、Fe 和 Fi）？

#### 4.3 常见错误

| 错误 | 表现 | 纠正 |
|------|------|------|
| 功能标签化 | 角色做了一件善事就标 Fi，做了一件果断的事就标 Te | 回到功能定义，检查行为特征是否匹配 |
| 忽略功能位置 | 把主导 Se 和劣势 Se 写成了同一种表现 | 明确标注功能在功能栈中的位置，写出位置带来的差异 |
| 过度分析 | 一段简单的日常互动被解读出五六个功能的激活 | 每段聚焦 1-2 个功能，宁可少说不可乱说 |
| 脱离剧情 | 分析变成了脱离具体场景的人格科普 | 每个分析点都必须回到这段剧情中的具体事件 |
| 结论先行 | 先决定要写什么功能，再去原文里找证据凑 | 先看角色做了什么，再判断这是哪个功能 |

### Step 5：撰写引言与结语

#### 5.1 引言

引言需要完成三件事：

1. **标明两个角色的 MBTI 类型和功能栈**，让读者一眼看到双方的认知结构
2. **点出两个类型之间的结构关系**（如逆位排列、互补关系等），这是后续所有分析的理论基础
3. **用一两句话概括这对角色关系的核心张力**，作为全文的阅读线索

引言不需要太长，5-8 句话即可。它的作用是给读者一副"眼镜"，戴上这副眼镜再去看后面的 20 个桥段，会更有方向感。

#### 5.2 结语

结语回到全局视角，概括 20 个桥段呈现出的整体图景：
- 两个角色在认知功能层面经历了怎样的碰撞和变化？
- 这对关系的核心动力是什么？（如"本能对阵算计""感官对阵直觉"）
- 用一个简洁的判断收尾

结语控制在 3-5 句话。

---

### Step 6：自检与校验

#### 6.1 逐段检查

每个桥段完成后检查：

- [ ] **剧情准确性**：简述中的事实是否与原文一致？有没有张冠李戴？
- [ ] **功能判断准确性**：标注的认知功能是否与知识库定义一致？
- [ ] **功能-行为绑定**：每个功能标注是否对应了角色的一个具体行为？
- [ ] **分析焦点**：这段分析是否聚焦于 1-2 个功能，而非泛泛列举？
- [ ] **位置差异**：如果两个角色用了同一个功能（如都涉及 Se），是否写出了位置不同带来的表现差异？

#### 6.2 全局检查

全部桥段完成后检查：

- [ ] **时间线连贯**：20 个桥段的排列是否符合故事的时间线顺序？
- [ ] **功能覆盖**：两个角色各自的前四项功能是否都出现了？
- [ ] **弧线完整**：从相识到结局的故事弧线是否完整，没有大段空白？
- [ ] **分析角度多样**：是否存在多段连续从同一个角度分析的情况？（比如连续三段都在讲 Se 的即时反应）
- [ ] **两个角色篇幅均衡**：是否一方被分析得明显多于另一方？
- [ ] **桥段标题区分度**：20 个标题是否各不相同、一看就知道是哪段戏？

## 关键判断指南

### 如何判断角色在用哪个功能

这是整个任务中最依赖判断力的环节。以下是一套可操作的判断流程：

**第一步：看角色做了什么**
把角色在这段剧情中的行为提取出来，用最朴素的语言描述。

**第二步：看行为的驱动方向**
- 行为是朝向外部世界的（影响环境、与他人互动、推动事情发生）→ 外倾功能
- 行为是朝向内部世界的（内心判断、自我审视、依据内在标准决策）→ 内倾功能

**第三步：看行为的性质**
- 行为关于"接收信息"（观察、感知、联想、预感）→ 感知功能（S 或 N）
- 行为关于"做出判断"（评估、决策、排序、取舍）→ 判断功能（T 或 F）

**第四步：结合角色的功能栈位置，确认**
- 这个功能在角色的功能栈中处于什么位置？
- 角色使用这个功能时的状态（自然流畅 vs 笨拙紧张 vs 失控暴走）是否与该位置的预期一致？

**示例**：
```
行为：樊长玉听到流言后，端起猪血水泼过去
→ 朝向外部世界（直接作用于环境）→ 外倾
→ 关于"接收并即时反应"（感官刺激→即时行动）→ 感知
→ 外倾 + 感知 = Se
→ Se 是 ESFP 的主导功能 → 使用状态自然流畅 → 符合
```

### 如何处理"两个功能联动"的情况

很多时候角色的行为不是单一功能的产物，而是两个功能的协同结果。处理方法：

1. 拆分行为的两个层面。比如"她毫不犹豫地把濒死的人背回家"——"毫不犹豫"是 Se 的即时反应，"要救他"是 Fi 的价值判断。
2. 分别标注两个功能，说明它们各自负责行为的哪个层面。
3. 指出两个功能的协同方式：是同时运作、是先后触发、还是一个功能的结果成为另一个功能的输入。

### 如何处理"劣势功能爆发"

劣势功能爆发是最具戏剧张力的分析点，但也最容易误判。确认劣势功能爆发需要满足以下条件：

1. **角色的行为明显偏离了他的常态模式**（INTJ 不再冷静计算，ESFP 突然陷入对未来的恐惧）
2. **存在极端的外部刺激**（至亲受威胁、核心价值被践踏、生死关头）
3. **行为的表现具有失控感**（做了平时绝不会做的事，事后可能后悔或记不清细节）

如果只满足其中一个条件，更可能是第三功能的发展性使用，而非劣势功能的爆发。

## 常见陷阱

| 陷阱 | 表现 | 应对 |
|------|------|------|
| 素材依赖 | 原文写得生动的段落被选为核心桥段，原文写得干巴的段落被忽略，哪怕后者在剧情和功能分析上更重要 | 选桥段的标准是功能可读性和关系推进价值，不是原文的文字质量 |
