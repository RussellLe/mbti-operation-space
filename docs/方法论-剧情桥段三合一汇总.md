# 方法论：剧情桥段三合一汇总

## 任务定义

**输入**：
- **剧情短诗**：基于 MBTI 八维与剧情素材创作的浮士德风格四行短诗（`{作品名}-剧情短诗.md`）
- **共鸣文案**：从剧情中提炼的 MBTI 性格共鸣文案（`{作品名}-共鸣文案.md`）
- **MBTI 解读**：贴着剧情写的八维认知功能分段解读（`{作品名}-MBTI解读.md`）

**输出**：一份最终汇总文档，将上述三类素材按剧情桥段编号对齐、合并，形成每个桥段"短诗 + 共鸣 + 解读"的完整结构，可直接用于社媒发布或进一步编辑。

**核心定位**：这不是二次创作，而是素材装配。三类内容各自已经过独立的创作和质检流程，本步骤的任务是准确对齐、规整格式、确保完整性。

---

## 执行步骤

### Step 1：确定纳入范围

从全部剧情桥段中筛选出要纳入最终汇总的桥段编号和标题，在文档顶部以清单形式列出。

```
# 纳入剧情
- 16.【背山救驾与初吻】
- 17.【私自出宫与暴君之怒】
- ...
```

筛选标准由人工判断：通常选择情感张力最强、MBTI 特质展现最鲜明的桥段。

### Step 2：按桥段编号对齐三类素材

从三个源文件中，按桥段编号分别定位对应内容：

| 素材类型 | 源文件命名规范 | 定位方式 |
|---------|-------------|---------|
| 短诗 | `{作品名}-剧情短诗.md` | 按 `### {编号}.` 标题定位 |
| 共鸣文案 | `{作品名}-共鸣文案.md` | 按 `### {编号}.` 标题定位 |
| 解读 | `{作品名}-MBTI解读.md` | 按 `### {编号}.` 标题定位，提取 `**解读：**` 之后的正文 |

注意：
- 短诗文件中每首诗带有副标题（如 `**【INTJ视角：Ni预判崩溃与Fi防线决堤】**`）和编号标题（如 `### 16. 碾碎堡垒的呼吸`），汇总时只取诗文正文（四行诗句），不带副标题
- 共鸣文案直接取正文段落
- 解读文件中每段包含 `**剧情：**` 和 `**解读：**` 两部分，汇总时只取 `**解读：**` 之后的全部正文

### Step 3：按统一格式装配

每个桥段按以下格式组装：

```markdown
# 【桥段标题】
### 短诗
{四行诗句，无副标题}
### 共鸣
{共鸣文案正文}
### 解读
{解读正文，不含剧情描述部分}
```

桥段之间不加分隔线，直接以 `#` 标题区隔。

### Step 4：完整性检查

逐个桥段核对：

- [ ] 短诗是否存在且完整（四行）
- [ ] 共鸣文案是否存在且对应正确的桥段编号
- [ ] 解读是否存在且对应正确的桥段编号
- [ ] 三部分的桥段编号是否一致（防止错位）

如某个桥段的某类素材尚未产出（如短诗文件为空），在汇总文档中暂不填入该部分，待素材就绪后补充。

## 文件组织规范

### 目录结构

```
workspace/{作品名}/
├── {作品名}-剧情梗概.md      # 原始剧情梗概（上游输入）
├── {作品名}-剧情短诗.md      # 短诗产出
├── {作品名}-共鸣文案.md      # 共鸣文案产出
├── {作品名}-MBTI解读.md      # 八维解读产出
└── 最终汇总.md               # 三合一汇总（本方法论的产出）
```

### 命名约定

- 源文件以 `{作品名}-{内容类型}.md` 命名
- 汇总文件固定命名为 `最终汇总.md`，放在同一作品文件夹下

---

## 常见问题

| 问题 | 处理方式 |
|------|---------|
| 某个桥段的短诗尚未创作 | 汇总中该桥段只放共鸣和解读，短诗部分待补 |
| 源文件中桥段标题与汇总清单不完全一致 | 以汇总清单中的标题为准，统一措辞 |
| 解读文件中包含 `**剧情：**` 段落 | 汇总时只取 `**解读：**` 之后的内容，剧情描述不纳入 |
| 需要调整桥段顺序 | 汇总中的顺序可以与源文件不同，按叙事节奏或发布需要自行排列 |
