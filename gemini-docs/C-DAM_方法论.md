# C-DAM: 叙事深度分析与理论映射方法论 (Character-Driven Deep Analysis Methodology)

本手册旨在指导 AI Agent 执行高质量的叙事文本分析，通过将特定理论框架（如 MBTI 荣格八维、心理学原型等）与文学/剧本素材深度对齐，产出具有深度洞察力和逻辑严密性的分析报告。

---

## 1. 核心执行步骤 (Execution Workflow)

### 第一阶段：原始素材解构 (Deconstruction)
1. **格式转换与提取**：若原始素材为非文本格式（如 `.docx`, `.pdf`），优先使用工具（如 `textutil`, `pandoc`）转换为纯文本，确保信息无损提取。
2. **全量扫描与索引**：对文本进行预读，识别关键人物关系、核心冲突点及高光场景。
3. **建立证据库**：记录具有代表性的台词、行为和细节，为后续理论映射准备“原材料”。

### 第二阶段：理论框架对齐 (Framework Priming)
1. **激活领域知识**：调取或学习目标理论的底层逻辑（如：认知功能的定义、运作机制、层级关系）。
2. **设定分析维度**：明确人物的核心驱动力（主导功能）、辅助平衡、成长短板（劣势功能）以及压力下的失控表现（阴影/劣势爆发）。

### 第三阶段：维度映射与深度合成 (Mapping & Synthesis)
1. **行为->动机映射**：不只是描述“发生了什么”，而是分析“为什么发生”以及“这反映了哪种认知偏好”。
2. **双轴碰撞分析**：分析多个人物互动时，不同维度/功能之间的张力。
    - *示例：当一方的 Ni（远见）碰撞另一方的 Se（即时反应）时，产生的冲突或互补。*
3. **极限状态探测**：寻找人物在极端压力下的行为异化，这是验证人物底层逻辑最强有力的证据。

### 第四阶段：迭代与密度增压 (Refinement)
1. **多级展开**：根据需求，将单一场景拆解为多个子维度进行深挖。
2. **语义增压**：剔除冗余修饰，增加专业术语的使用频次与准确性。

---

## 2. 产出要求 (Output Standards)

### A. 通用性要求
*   **结构化**：必须包含引言、核心功能对照表、逐点深度拆解、总结等模块。
*   **证据链**：每一条理论推论必须紧跟一个具体的剧情桥段引用。
*   **双向验证**：分析 A 对 B 的影响时，必须同时给出 B 对 A 的反馈分析。

### B. 具体产出模板标准
1.  **维度定义表**：清晰定义分析对象的理论画像（如 MBTI 类型及其功能栈）。
2.  **剧情桥段解析项**：
    - **【桥段名称】**：具有辨识度的短标题。
    - **剧情简述**：简洁、准确地复述核心动作。
    - **深度解析**：
        - 识别所使用的理论维度（如：Se 爆发）。
        - 阐述该行为如何符合该维度的定义。
        - 描述该行为对叙事走向或人物关系的底层意义。
3.  **结语/升华**：从宏观角度总结该配对/人物在理论框架下的宿命感或成长性。

---

## 3. 底层方法论与核心规则 (Underlying Rules)

为确保产出质量的一致性，执行 Agent 必须遵循以下底层规则：

1.  **逆向还原法 (Reverse Reconstruction)**：
    *   不要先入为主。先观察行为，再寻找匹配的理论标签；然后反过来，用理论标签预判人物在其他场景的潜在反应，若吻合则逻辑自洽。

2.  **张力最大化原则 (Tension Maximization)**：
    *   重点关注人物功能栈中的“劣势功能”或“功能冲突点”。最精彩的分析往往不在于人物做得好的地方，而在于他们如何面对自己最笨拙、最失控的领域。

3.  **语义密度守恒 (Semantic Density)**：
    *   若用户要求“增加篇幅”，Agent 应通过**增加分析维度**和**挖掘微小细节**来填充，严禁使用废话填充。每一段文字都应提供新的信息增量。

4.  **去语境化防御 (Context Preservation)**：
    *   在进行理论映射时，严禁脱离叙事背景。必须考虑人物的阶级、职业、生存压力等环境变量对认知表现的影响。

---

## 4. 经验总结 (Best Practices)

*   **并行检索**：在分析长篇文本时，使用 `grep_search` 或 `generalist` 子 Agent 并行提取不同人物的桥段，可以极大提高效率。
*   **术语精准**：使用如“劣势功能爆发”、“认知闭环”、“物理降维”等具有心理学/哲学深度的词汇，能显著提升报告的专业感。
*   **反馈响应**：当用户要求“更多”时，通常意味着 Agent 忽略了一些“细枝末节但具张力”的细节。此时应重启扫描，寻找那些非主线、但在情感/逻辑上具有爆发力的“微瞬间”。
