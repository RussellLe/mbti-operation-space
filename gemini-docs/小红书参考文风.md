# ENTP女到底啥样
最明显的就是反差和随性。
	
人群中的小太阳，特别像个交际花，看起来就是傻白甜小妖精这一类型。不是卖弄风情那种，就是那种开开心心说话爱和大家玩又特别随意的社牛。
	
但时间长了你会发现她是一个特别深刻的人，肯定有阅读，学习之类的爱好。这时候你会发现她是那种很积极在努力的类型，就有第一层反差。
然后再深一些，你会发现她极其厌世，觉得人生并没有意义，冷静看待这个世界的所有，万物皆可讲道理。这个环节你会发现她有点可怕，在特别热的外表下，有个特别冷静的内心。
	
然后再接触，如果到亲密关系这一层。就会发现，她是一个既矛盾又统一的整体。就是什么都懂，既能理解痛苦，又愿意沉迷于世俗的快乐里，但同时觉得毫无意义，可行为又特别积极。
	
我觉得这种感觉女生男生都是特别极其特别的存在，就是她只要在那里你一定会发现她哪里不一样。因为我从小到大不管在哪个环境，都会被认为，和别人都不一样。这个其实一半一半，有很大的原因是环境造成的。应该是在一个言论宽松而且比较封闭简单的环境里长大的。
